# AI Handbook — Chapter 3

Python examples for Chapter 3 of the AI handbook.

## Examples

- `example3.1.py` — calculates predictions and mean squared error for a simple linear model.
- `example3.2.py` — calculates a weighted neuron sum and applies a ReLU activation function.
- `example3.3.py` — trains a linear regression model with scikit-learn and predicts a new score.

## Requirements

Example 3.3 requires scikit-learn:

```bash
pip install scikit-learn
```

## Running the examples

From the repository root:

```bash
python example3.1.py
python example3.2.py
python example3.3.py
```
